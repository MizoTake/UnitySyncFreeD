# UnitySyncFreeD

UnitySyncFreeD is the development repository for the Unity UPM package `com.mizotake.syncfreed`.

The package focuses on Free-D camera sync and packet output:

- Free-D D1 29 byte packet build and parse
- UDP unicast, multi-destination unicast, multicast, and loopback checks
- Unity camera, tracker, replay, controller, diagnostics, and sample scenes
- Pure C# core, Unity adapters, Editor tooling, Samples, and Unity Test Runner coverage

Package entry point:

- `Packages/com.mizotake.syncfreed/package.json`
- `Packages/com.mizotake.syncfreed/README.md`
